# Project Proposal: Cloud Migration for SCADA Data Systems
**Client:** Sahara Power & Energy
**Date:** November 2023

## Business Problem
Following the success of the Centralized AI Platform for Grid Analytics
(PRJ-027), Sahara Power wants to migrate the underlying SCADA
(Supervisory Control and Data Acquisition) data historian systems to the
cloud, to support further analytics use cases beyond what the current
on-premise infrastructure can scale to.

## Proposed Solution
A **Cloud-First AI** engagement: migrating SCADA historian data to an
Azure/Kubernetes-based cloud infrastructure ahead of layering additional
analytics capabilities on top, following the same infrastructure-first
sequencing logic used in the grid analytics program.

## Expected Outcomes
- Scalable cloud infrastructure for SCADA data, removing the on-premise
  capacity ceiling
- Foundation for future analytics use cases beyond current grid
  analytics scope

## Key Assumptions
- Migration approach and change-management practices proven on the
  Centralized AI Platform engagement (an IT-led, IT-owned program) will
  transfer to this engagement
- SCADA systems, while operationally more sensitive, can be migrated
  using a comparable IT-led migration methodology

## Strategy & Approach
Cloud-First AI is proposed given Sahara Power's existing on-premise SCADA
infrastructure and the clear precedent of the successful grid analytics
platform. We note that SCADA systems sit closer to live operational
control (as opposed to grid analytics, which is an analytics layer on
top of operational data) — this distinction is acknowledged but not
treated as requiring a materially different migration methodology in
this proposal.

## Indicative Investment
Estimated budget: $1.85M-$1.95M over an estimated 16-month engagement.
