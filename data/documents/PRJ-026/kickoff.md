# Kickoff Document: Network Anomaly Detection Pilot
**Date:** July 14, 2023
**Project ID:** PRJ-026

## Stakeholders
- **Client sponsor:** Zenith Mobile UAE, Head of Network Operations
- **NexaAI Project Manager:** Daniel Haddad

## Objectives
1. Deploy anomaly detection on the pilot infrastructure subset
2. Validate early-detection improvement versus threshold-based alerting
3. Produce a network-wide rollout recommendation

## Initial Team
3-person team, the smallest in the current portfolio, reflecting the
narrowly-scoped pilot.

## Initial Plan
Weeks 1-3: model development against historical network performance
data. Weeks 4-9: live monitoring and comparison against existing
threshold-based alerts.
